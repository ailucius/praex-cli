# Homebrew tap for Praex

Praex is an open source (MIT) AI coding agent for the terminal. https://praex.ai

## Install

```bash
brew install downoff/tap/praex
```

Works on macOS (Apple Silicon and Intel) and Linux x64.

## Update

```bash
brew upgrade praex
```

The formula downloads the prebuilt release binaries from https://github.com/ailucius/praex-cli/releases and checks their SHA256 hashes. It is generated by `packaging/homebrew/generate-formula.mjs` in that repository.
